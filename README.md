[![Dataset](https://img.shields.io/badge/Dataset-Release-green.svg)]() [![License](https://img.shields.io/badge/License-MIT-blue.svg)]() 

## 📖 简介 (Introduction)

**MFEA-Dataset** 是一个专为机车转向架等工业产品三维模型特征面识别而构建的**工业级语义分割数据集**。

针对现有面向工业产品的加工特征识别数据集普遍存在的**特征类型单一**、**几何复杂度不足**、**与真实零件差距大**以及**语义层级划分粗糙**等局限性，本数据集旨在为结构件加工特征的语义解析与点云数据的语义判别提供高质量、贴近真实工业场景的数据支持。

---

## ✨ 核心特性 (Key Features)

* **🏷️ 多层级语义标签策略**
    针对复杂工业产品（如机车转向架）易出现的语义混淆与结构多变问题，数据集设计了精细的标签体系：
    * 包含**“结构相似但语义不同”**的对抗性样本。
    * 包含**“语义一致但结构不同”**的多样性样本。
    * *优势*：大幅提升模型在复杂场景下的鲁棒性与泛化能力。

* **⚙️ 真实的工业级拓扑复杂度**
    以工业领域典型“齿轮类零件”为试验案例，引入了轮毂、辐板、减重孔等真实的附加结构，极大地增强了三维模型的几何耦合性与拓扑复杂性，填补了现有数据集与真实工业零件之间的鸿沟。

* **🔄 自动化的精准标注管线**
    通过建立 `设计参数 -> 几何构造 -> 拓扑单元` 之间的可追溯映射关系，实现了多层级语义标签的全自动、零误差标注。

---

## 🛠️ 数据集构建方法 (Dataset Construction)

本数据集的生成与扩展过程严格遵循工业标准：
1.  **参数化驱动**：基于真实的机械设计公式进行参数生成与三维模型扩展。
2.  **特征融合**：在基础模型上叠加各类复杂工业特征（如减重孔、辐板等）。
3.  **语义追溯**：利用参数生成过程中的拓扑映射关系，直接导出具备多层级语义信息的分割标签（点云/网格）。
